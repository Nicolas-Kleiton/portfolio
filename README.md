Hello! Welcome to the repository of my personal portfolio. I built this space to centralize my projects, share my professional journey, and make it easy for anyone to connect with me.

**🌍 Check it out live:** [nicolas-kleiton-portfolio.vercel.app](https://nicolas-kleiton-portfolio.vercel.app)

## 🛠️ What I used

I chose to use **Angular** (currently version 21) to structure the entire application. In addition, the project was built with:
- **TypeScript** - to ensure type safety;
- **SCSS** - to keep the styling flexible, modular, and organized.

## 🧩 Structure

The interface is structured into independent components to make it easier to maintain and scale:
- **Hero**: A prominent and modern introductory section.
- **About**: A brief overview of my profile, education, and technical stack.
- **Featured Project**: Highlighting my most impactful and relevant projects.
- **Contact**: Contact links and professional networks.

## 🚀 How to run it locally (for developers)

If you are a developer and want to clone this repository to run it locally on your machine:

1. Clone the repository:
```bash
git clone https://github.com/Nicolas-Kleiton/portfolio.git
```
2. Go into the project folder:
```bash
cd portfolio
```
3. Install dependencies:
```bash
npm install
```
4. Start the development server:
```bash
npm start
```
After that, just open `http://localhost:4200/` in your browser.
